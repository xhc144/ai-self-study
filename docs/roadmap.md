# 依赖关系与学习路线

先理解条件文本预测，再学参数学习和注意力；评价为数据、算力与后训练的比较提供共同标准。后训练与推理预算连接工具可靠性，机制干预与可核验研究再提出新问题。矩阵、概率、微分附录只在需要时回查。

```mermaid
flowchart LR
 A[条件文本预测] --> B[参数学习与梯度]
 B --> C[因果注意力与缓存]
 C --> D[评价、数据与算力]
 D --> E[后训练与推理预算]
 E --> F[工具与信任]
 F --> G[机制解释与研究闭环]
 G --> H[条件记忆、形式核验与循环状态]
 M[矩阵/概率/微分工具] -. 按需回查 .-> B
 M -.-> E
```
