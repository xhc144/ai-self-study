# 来源、权利与适用范围

正文是围绕本项目问题写成的原创中文教学稿、数学推导与思想解释；没有翻译或粘贴第三方整章、图表或论文。公式与标准定义按其数学事实解释，出处见 [机器可读来源账本](sources.json)。

- 用户明确请求采用 `math-lecture-writing`、`math-latex-typesetting` 与 `latex-pdf-editorial`。采用用户指定的固定王者模板；它是 book + ctex + amsthm 的适配类，不是官方 ElegantBook。该特定排版要求优先于另一 PDF skill 的默认短文样式。
- 固定模板通过用户提供的 skill 获得；随本次被授权的完整源码交付提供，保留其原提供者权利。项目的原创内容许可证不自动覆盖模板。若单独复用该模板，应取得原提供者相应许可。
- 源码不捆绑字体。Fandol 和 Computer Modern Unicode 从本地 TeX 环境加载；再分发字体需分别遵守字体许可证。
- 免费可读不等于开放翻译/镜像许可。Goodfellow、Boyd、MML 等只链接官方来源，不打包 PDF 或整章译文。
- D2L 正文与示例代码有不同许可。本项目没有复制其源码或正文，不假称全部采用 Apache/MIT。
- arXiv 收录本身不赋予通用再分发权。每条论文的许可和本项目使用边界记在 `sources.json`，无需转载全文即可讨论其思想与限制。
- 所有实验数据均为本项目脚本生成的有限语法、数值特征、动作偏好和字符串案例；没有用户私人文件、课程受限数据或真实秘密。
- 原创图由实际指标生成，无第三方截图拼贴。编译 PDF 的标准字体嵌入属于 TeX 构建流程，源码包不提供可安装字体文件。
