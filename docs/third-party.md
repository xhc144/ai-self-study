# 来源、权利与适用范围

原创中文教材、研究说明、数学推导与实验独立编写。选定论文的全文译文和原作者图件另按精确来源版本署名，不混入原创MIT代码范围。

- [论文许可账本](../papers/rights.json)记录版本、官方许可证据、是否选择完整翻译；逐篇 `metadata.json`、`coverage.json`、图件权利记录说明具体改动和例外。CC BY 4.0译文包含许可链接、原作者、出处和修改说明。
- R1采用2025-09-17 Nature正式本体（含Methods和Extended Data）；AlphaProof采用2026-03-13 Nature Version of Record本体。独立补充文件未因主文CC许可而自动镜像或宣称完成翻译。arXiv R1的许可也未借用Nature授权。
- IH-Challenge及Anthropic浏览器报告未见开放全文改编授权，采用原创研究说明和少量事实概括，不提供全文译本/原图镜像。其他未选版本只提供链接、原创思想分析或后续阅读入口。
- DGM论文附录内15段原代码/差异补丁按论文CC BY 4.0保留，位于 `papers/translations/dgm/code/`，与本项目原创实验代码的MIT许可区分；这些代码仅展示，不在实验/构建时执行。
- 图中若注明来自另一作品，另核原来源许可并保留credit，不用本论文CC许可包办。英文字标签附中文解释，保留作者数据曲线，不能标成我们复现的结果。
- 用户指定固定王者数学模板；其适配类为 `book + ctex + amsthm`，不是官方ElegantBook。随授权源码交付保留原提供者权利，项目原创许可证不独立为继承模板授予新许可。
- 源码不捆绑字体，Fandol与Computer Modern Unicode由读者TeX环境提供。PDF正常嵌入字体，源码包不提供可安装字体文件。
- 官方教材免费阅读不等于可以翻译或镜像；Goodfellow、Boyd、MML等只链接。D2L正文与代码许可分别适用，本项目未复制课程作业。
