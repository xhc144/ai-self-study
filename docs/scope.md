# 本版范围

0.3.0是一份现代AI研究学习教材、九篇指定许可版本的全文中文资料、三份原创研究说明以及真实CPU实验。材料以现代基础模型的方法/证据问题链组织，数学工具后置，不机械扩充旧版13章。

全文范围以各篇官方指定版本本体及其所含附录为准；R1/AlphaProof独立补充文件不自动纳入。未许可资料采用原创解释，不标成完整译本。我们的机制实验、实际小Transformer训练、135M诊断与原作者前沿模型结果分别标明。

理解“智能如何产生”以任务定义、学习与推断、表示和证据为入口；没有单个定理证明一般智能/意识从规模必然产生，也不把解释性或稳定性当成语义正确证明。后续研究须新增可证伪设计而不是把小实验外推为前沿系统复现。
