\originalchapter{AI 进步的资源与机制}\label{ch:progress}
\originalsection{多种进步共同作用}
理解 AI 为什么发展迅速, 需要把能力、成本与测量协议放在同一张地图上. 可扩展架构使更多计算能被有效利用; 大规模数据提供广泛的统计规律; 优化与硬件系统降低一次训练的成本; 后训练让模型更适合用户目标; 推理时的搜索、工具和验证又能改善一次任务的结果. 这些因素相互作用, 没有一个单独构成智能的充分条件.

Transformer 的训练可以在序列位置上并行, 相比必须逐步处理的简单循环网络减少顺序依赖. 但自回归生成仍要逐步采样, 并行训练不等于并行生成. 数据去重、混合、质量过滤也会改变同样 token 数的有效信息. “训练了更多数据”必须同时说明数据分布、重复率和评价污染.

从预测目标到复杂能力的一个合理机制假说是: 为了在多样文本中准确预测, 模型需要表示语法、实体、关系、算法和情境. 比如准确续写证明, 可能需要掌握某些推导关系. 这是训练压力的解释, 不是证明任意最低损失模型都学到真实世界的因果结构. 有限数据也可以被记忆, 而“一个目标”可以容许多种内部实现.

\originalsection{规模规律与预算分配}
Kaplan 等人报告在所研究范围内, 语言模型交叉熵对参数、数据和计算呈近似幂律\cite{kaplan}. Hoffmann 等人的 Chinchilla 研究强调固定计算预算下, 参数和 token 数需要协同扩大\cite{chinchilla}. 它们是经验规律, 需要重新拟合的系数与范围, 不应理解为永恒物理定律.

考虑一个用于解释的简化模型: 参数数 $N$, token 数 $D$, 损失为
\[
L(N,D)=L_\infty+aN^{-\alpha}+bD^{-\beta},\qquad a,b,\alpha,\beta>0.
\]
令训练计算近似为 $C=kND$, 这里忽略序列长度、架构、硬件利用率和额外系统成本. 固定 $C$ 后, $D=C/(kN)$, 则
\[
L(N)=L_\infty+aN^{-\alpha}+b(kN/C)^\beta.
\]
对 $N$ 求导并令零, 得
\[
\alpha aN^{-\alpha}=\beta bD^{-\beta},\qquad
N_*\propto C^{\beta/(\alpha+\beta)},\quad D_*\propto C^{\alpha/(\alpha+\beta)}.
\]
第一关系表示两类误差下降的边际收益平衡. 由于 $N\to0$ 或 $N\to\infty$ 都使一项发散, 且该平衡式对 $N$ 的两侧单调相反, 正驻点唯一并为最小值. 这段推导是本书对简化假设的分析, 不是原论文全部拟合方法的复述.

若 $\alpha=\beta$, 参数与数据均随 $C^{1/2}$ 扩大. 若部署时要生成海量 token, 推理成本也应计入目标, 最优训练点可能改变. 数据质量、重复 token、架构、训练时长与下游指标变化也可能改变估计的最优分配. 因而不能从一个近似比例推出所有模型都应采用同样 token/参数比.

本项目只有一个很小的语言模型配置, 完全不具备拟合真实规模规律的实验覆盖. 它可以让读者检查预算对象, 不能让读者“证明”大模型幂律. 若要自己研究规模规律, 需要多个模型尺寸和数据预算, 各自收敛诊断、固定评价分布与外推保留点.

\originalsection{涌现与指标}
设一项任务要求 $m$ 个步骤全部正确, 简化假设每步独立且成功概率为 $p$. 全题成功率为 $p^m$. 当 $m=20$, $p$ 从 0.7 到 0.9 时, 全题率从约 $0.0008$ 到 $0.1216$, 视觉上可以像突然出现的能力. 但每步概率始终连续, 没有推出内部机制发生突变. 独立性只是算例假设, 真实步骤错误通常相关.

Schaeffer 等人讨论了不连续指标与统计对“突然涌现”图像的影响\cite{emergence}. 这不否认大模型取得真实提升, 也不证明所有新行为都能由指标解释. 一个严谨研究应同时看连续概率、部分得分和精确匹配, 保留失败样本, 再检验不同机制是否能解释曲线.

任务本身也会改变: 若评测从知识问答变成允许搜索、工具和多次采样, 分数提升包含整个系统的贡献. 同样名称的 benchmark 在不同版本、提示、污染或评分规则下并非同一测量. 模型参数量也不是总成本的代理, 它遗漏训练数据、后训练、教师生成、搜索与运行系统.

\originalsection{练习与解答}
\begin{exercise}
在简化损失模型中取 $\alpha=1/2,\beta=1$. 当训练计算增加 8 倍, 最优参数和 token 数各增加多少倍?
\end{exercise}
\begin{solution}
指数分别为 $2/3$ 和 $1/3$, 所以参数增加 $8^{2/3}=4$ 倍, token 增加 $8^{1/3}=2$ 倍. 两者乘积为 8, 与固定 $k$ 的计算约束相符. 这只在简化模型和常数不变时成立.
\end{solution}
\begin{exercise}
一个系统允许采样 100 个候选再由正确性 oracle 选择, 另一系统只生成一次. 前者成绩更高可以支持什么结论? 怎样作更公平比较?
\end{exercise}
\begin{solution}
它支持前者在包含 100 次采样和 oracle 的系统预算下表现更好, 不能单独归因为基础模型更强. 应同时报告单次生成正确率、预算曲线、实际选择器性能和总时间, 并在相同候选数或其他明确成本约束下比较. Oracle 的存在本身可能是现实中无法获得的优势.
\end{solution}
