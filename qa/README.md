# 如何阅读验收证据

旧版报告保留其版本和原快照。`v03-*` 绑定首次完整0.3.0交付；0.3.1修订另用 `v031-*` 报告说明改动页、打包及来源哈希的增量检查。不要把作者隔离编译、独立源码审查和最终PDF检查当成同一层证据，也不要把旧PDF的PASS自动移到修改后的文件。

- `v031-disclosure-independent-review.md/json`：独立核对12个不同输入、36种输入/模型/格式组合、重复组一致性以及后验去重计数，冻结设计与指标不变；此报告只覆盖源码与存档数据，不覆盖新PDF。
- `v031-final-pdf-*` 与 `v031-collection-independent-review.md/json`：改动组件实际全页渲染、变页高清核查，以及393/492页合集与当前组件的完整内容和链接对应。
- `v031-reproducibility.json`：新ZIP的fresh增量重编与58测试；不变的实验文件按散列绑定已完成的0.3.0全套真实复现，未重跑模型。`v03-pdf-signatures.json`是构建器使用的当前内容签名，旧签名保留在`v0.3.0`历史。

- `v03-independent-book-review.md`：现代主线、数学工具、新实验与原创研究说明的独立读者检查；保留首轮问题、修复和撤回的误判。
- `v03-*-independent-review.md`：精确官方版本的译文结构、数学、图表/书目/长示例与许可对照，区分全量机械核验和语义检查。
- `v03-final-pdf-*.md/json`：正式PDF逐页渲染、全部布局巡视、选定页面可读高分辨率检查、日志、链接与实际文件哈希。
- `v03-reproducibility.json`：从源码ZIP新目录重建PDF、测试、实验及指标比较。
- `v03-release.json`：最终内容与产物快照，范围、页数、许可证和测试记录。

全页布局巡视不等于逐句中英人工专家校订。数学检查、实际运行、编译成功、像素/文本/链接比较各自能排除不同问题；所有报告只覆盖写明的文件与版本。
