# 如何阅读验收证据

旧版报告保留其版本和原快照；本版使用 `v03-*` 文件。不要把作者隔离编译、独立源码审查和最终PDF检查当成同一层证据。

- `v03-independent-book-review.md`：现代主线、数学工具、新实验与原创研究说明的独立读者检查；保留首轮问题、修复和撤回的误判。
- `v03-*-independent-review.md`：精确官方版本的译文结构、数学、图表/书目/长示例与许可对照，区分全量机械核验和语义检查。
- `v03-final-pdf-*.md/json`：正式PDF逐页渲染、全部布局巡视、选定页面可读高分辨率检查、日志、链接与实际文件哈希。
- `v03-reproducibility.json`：从源码ZIP新目录重建PDF、测试、实验及指标比较。
- `v03-release.json`：最终内容与产物快照，范围、页数、许可证和测试记录。

全页布局巡视不等于逐句中英人工专家校订。数学检查、实际运行、编译成功、像素/文本/链接比较各自能排除不同问题；所有报告只覆盖写明的文件与版本。
